# «Костя Гій!» — кожен крик вдвічі гучніший

**Готове відео:** [`Костя_Гій_9x16.mp4`](Костя_Гій_9x16.mp4): 32 с, 1080×1920, 30 fps, AAC, −14 LUFS.

Ескалаційний TikTok у форматі референсу з `projects/ai-rabotai-umnee/`: low-poly 3D, HUD зліва вгорі, 12 кроків, анти-клімакс у космосі.
Герой у чорному спортивному костюмі кричить «Костя Гій!» щоразу вдвічі гучніше (у дБ). Костя в помаранчевому худі йде в навушниках і нічого не чує.
Місто тим часом розлітається. Наприкінці крик №12 у вакуумі: 0 дБ. Костя знімає навушники: «Га? Шо?»

## Як зібрати

Потрібні Python, numpy, pillow, scipy і imageio-ffmpeg. Двигун — власний софтверний растеризатор (`engine.py`), GPU не потрібен.

```bash
python render.py preview 3.0 12.5 30.0        # кадри у work/
SS=2 python render.py video 0 16 work/part1.mp4 & SS=2 python render.py video 16 32 work/part2.mp4 & wait
python mix.py                                  # work/mix.wav
ffmpeg -f concat -i work/list.txt -c copy work/video.mp4
ffmpeg -i work/video.mp4 -i work/mix.wav -af "loudnorm=I=-14:TP=-1.5:LRA=11,volume=-2dB,alimiter=limit=0.89" \
  -c:v libx264 -preset slow -crf 19 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart Костя_Гій_9x16.mp4
```

Голоси: TTS українською (`assets/vo/`: `shout1/2.wav` — крикун, `kostya.wav` — «Га? Шо?»). Звукові ефекти — з набору (`assets/sfx/`).
Автосигналізація, скло, біт із навушників і бум — синтез у `mix.py`.
